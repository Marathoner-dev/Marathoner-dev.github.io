AWS / Terraform

월 10만 원 안에서 설계하고 운영하는 AWS

작은 팀이 실제 결제를 받는 서비스를 운영하려면, 안 죽어야 하고 비밀이 새면 안 되고 돈도 많이 들면 안 됩니다. Fargate, ALB, NAT 게이트웨이로 정석대로 짜면 가장 작게 잡아도 월 15만 원이 넘었습니다. 그래서 비용 상한부터 정하고, 그 안에서 안전하게 운영하는 구조를 설계했습니다.

비용 상한부터

dev와 prod를 합쳐 월 10만 원 안으로 정했습니다. EC2 한 대와 RDS micro로 예상 월 8~9만 원입니다. 사용자가 늘어날 때 옮겨 갈 Multi-AZ, Fargate 구성(월 약 54만 원)은 다음 단계로 문서에 남겨 뒀습니다.

SSH를 열지 않기

22번 포트는 닫고 80, 443만 엽니다. 서버 접속은 SSM Session Manager로만 하고, 비밀 값은 SSM Parameter Store에 둡니다.

오래 가는 키 없이 배포

GitHub Actions는 OIDC로 그때그때 역할을 받습니다. prod 배포는 GitHub의 production 승인을 거치고, prod 인프라 변경은 사람만 적용합니다.

망가져도 되돌릴 수 있게

RDS 자동 백업 7일로 초 단위 시점 복구를 하고, 삭제 방지를 켰습니다. 큰 마이그레이션 전에는 스냅샷을 찍고, CPU 80%, 남은 저장 공간 20%, 연결 수 알람과 예산 알림이 메일로 옵니다.
