AWS / Terraform

AWS, designed under a ₩100k monthly cap

A small team running a service that takes real payments needs uptime, no leaked secrets, and a small bill. The textbook setup with Fargate, an ALB, and a NAT gateway started above ₩150k a month. So the cost ceiling came first, and the design had to stay safe inside it.

Cost ceiling first

Dev and prod together stay under ₩100k a month. One EC2 host plus RDS micro comes to roughly ₩80-90k. The Multi-AZ Fargate setup (about ₩540k) is documented as the next step for when traffic grows.

No SSH

Port 22 stays closed, only 80 and 443 are open. Access goes through SSM Session Manager, and secrets live in Parameter Store.

Deploys without long-lived keys

GitHub Actions gets short-lived roles via OIDC. Prod deploys need a production approval in GitHub, and only a person applies prod infrastructure changes.

Recoverable by default

Seven days of RDS backups allow point-in-time recovery, and deletion protection is on. Snapshots precede big migrations, and alarms for CPU at 80%, storage at 20% left, connections, and budget go to email.

Plan by day, agents by night

I owned planning, design, and decisions. Implementation was done together with AI agents.

    Decide what to build, and why

    Write the plan and record the decisions.

  2. 18:00Me

    Hand off the night's work

    Scope it, and list what must not be touched.

  3. 02:00Agents

    Build and check

    Implement on branches and run the daily E2E check.

  4. 08:00Me

    Review the morning report

    Review the PRs. Merging and deploying stay with me.
